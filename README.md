<h2 align="center">
  <code>&gt; OVERVIEW</code>
</h2>

<div align="center">

<p>
  <strong>Bexora</strong> is a standalone desktop application designed to provide a centralized,
  fast and visually distinctive interface for Discord administration and authorized testing.
</p>

<p>
  The application is distributed as a single Windows executable:
</p>

<p>
  <code>Bexora.exe</code>
</p>

<br>

<p>
  <code>No Python installation</code><br>
  <code>No Node.js installation</code><br>
  <code>No dependency setup</code><br>
  <code>No additional files required</code><br>
  <code>No terminal required</code>
</p>

<br>

<h3>Just launch the executable.</h3>
